# Pile Load Testing Platform – Design System & Styling Guide

## 1. Design Philosophy

**Aesthetic:** "Precision Engineering." Clean, high-contrast, distraction-free.

**Core Principle:** Clarity over Flash. Field engineers work in bright sunlight; Reviewers look at dense data.

**Shape Language:** Slightly rounded corners (rounded-lg), distinct borders, and card-based grouping to separate distinct testing stages.

## 2. Color Palette

We use a Slate & Blue foundation to convey trust and engineering precision, with Emerald for safety/success indicators.

### Primary Colors

**Structure Blue (Primary Action):** `#2563eb` (Tailwind blue-600)
- Use: Main buttons, active tabs, load curves on graphs.

**Midnight Slate (Navigation/Brand):** `#1e293b` (Tailwind slate-800)
- Use: Sidebars, mobile headers, primary headings.

### Functional / Status Colors (Crucial for IS 2911 Checks)

**Safe / Passed:** `#10b981` (Tailwind emerald-500)
- Use: "Passed" badges, Net Settlement values within limits, Unloading curves.

**Warning / Check:** `#f59e0b` (Tailwind amber-500)
- Use: Pending Review status, readings approaching safety limits.

**Fail / Danger:** `#e11d48` (Tailwind rose-600)
- Use: "Failed" badges, Delete actions, Settlement exceeding limits.

### Backgrounds & Neutrals

- **App Background:** `#f3f4f6` (Tailwind gray-100) - Reduces eye strain.
- **Card Surface:** `#ffffff` (White)
- **Text Main:** `#1e293b` (Tailwind slate-800)
- **Text Secondary (Meta):** `#64748b` (Tailwind slate-500)
- **Borders:** `#e2e8f0` (Tailwind slate-200)

## 3. Typography

### Font Family

- **Web:** Inter or Segoe UI.
- **Mobile:** System Default (San Francisco on iOS, Roboto on Android) to feel native.
- **Data Entry:** JetBrains Mono or Roboto Mono (Crucial for aligning numerical data in tables).

### Scale

- **Page Title:** `text-2xl font-bold text-slate-800` (Mobile: text-xl)
- **Section Header:** `text-lg font-bold text-slate-700 uppercase tracking-wide`
- **KPI Value:** `text-3xl font-extrabold text-slate-900`
- **Body:** `text-sm text-slate-600`
- **Input Text:** `text-base font-medium text-slate-900` (16px minimum to prevent zooming on phones).

## 4. UI Components (Atomic Design)

### A. Cards (The Core Container)

Used for everything: KPI summaries, Graph containers, and Reading forms.

- **Style:** `bg-white rounded-xl border border-slate-200 shadow-sm p-4`
- **Mobile Behavior:** Full width.
- **Web Behavior:** Grid layout.

### B. Buttons

**Primary (Submit/Save):**
```
bg-blue-600 text-white font-semibold py-3 px-4 rounded-lg shadow-sm active:bg-blue-700
```

**Secondary (Cancel/Back):**
```
bg-white text-slate-700 border border-slate-300 font-medium py-3 px-4 rounded-lg active:bg-gray-50
```

**Ghost (Text Link):**
```
text-blue-600 font-medium hover:underline
```

### C. Input Fields (Field Data Entry)

Optimized for "Fat Finger" usage in the field.

- **Style:** `h-12 bg-white border border-slate-300 rounded-lg px-3 text-lg w-full focus:border-blue-500 focus:ring-2 focus:ring-blue-200`
- **Labels:** placed above inputs, `text-xs font-bold text-slate-500 uppercase mb-1`.

### D. Badges (Status Indicators)

Used for Test Status (Ongoing, Review, Signed).

- **Shape:** `rounded-full px-3 py-1 text-xs font-bold uppercase`
- **Success:** `bg-emerald-100 text-emerald-700`
- **Pending:** `bg-amber-100 text-amber-700`
- **Draft:** `bg-slate-100 text-slate-600`

## 5. Data Visualization Style (Graphs)

For the Load vs. Settlement/Deflection charts (Chart.js / Victory Native).

- **Grid Lines:** Dotted, color `#f1f5f9` (Very subtle).
- **Axes Labels:** `#64748b`, Font size 10px/12px.
- **Line 1 (Loading):** Solid, Color `#2563eb`, Width 2px.
- **Line 2 (Unloading):** Dashed (5,5), Color `#10b981`, Width 2px.
- **Limit Line (Safety):** Dotted, Color `#e11d48`, Width 1px (e.g., at 12mm settlement).
- **Points:** Radius 3px, White fill, Colored border.

## 6. Layout Patterns

### Web Dashboard (Next.js)

- **Sidebar Layout:** Fixed sidebar on the left (w-64), scrollable content on the right.
- **Grid System:**
  - KPIs: grid-cols-4
  - Main Content: grid-cols-3 (2 cols for Graph, 1 col for Specs).
- **Tables:** Sticky header `bg-slate-50`, row hover `hover:bg-slate-50`, dense text.

### Mobile App (Expo)

- **Stack Navigation:** Standard top header with Back button.
- **Bottom Tabs:** For major sections (Home, Active Tests, History).
- **Forms:** Single column, vertical stack.
- **Tables:** Horizontal scroll container for the "Readings" table, or "Card View" per reading row (better for small screens).

## 7. Report PDF Output Styling

The PDF generated should mimic the Web View but optimized for A4 paper.

- **Header:** Logos left/right, Project Title centered.
- **Footer:** Page numbers, "Generated by ZedGeo Platform", Sign-off box.
- **Print CSS:**
  - Avoid page breaks inside reading tables (`break-inside-avoid`).
  - High-resolution graph rendering.
  - Black text only for legal readability (except Pass/Fail badges).
